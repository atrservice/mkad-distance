# МКАД Дистанс

Публичный веб-калькулятор пробега спецтехники по дорогам Москвы и Московской области.
Пробег считается только по автомобильным дорогам, с привязкой к ближайшим съездам МКАД.

Продакшен: https://atrservice.github.io/mkad-distance/
Репозиторий: https://github.com/atrservice/mkad-distance (GitHub Pages, ветка `main`, корень).

## Что умеет (этап 1)

- Автоматический расчёт пробега при вводе адресов, без кнопки «Рассчитать».
- Адреса вводятся подсказками (Dadata / Nominatim) или координатами в десятичном виде (как в Яндексе).
- Правила пробега:
  - первый адрес снаружи МКАД → добавляется нога «МКАД → адрес 1» от ближайшего съезда;
  - последний адрес снаружи МКАД и тумблер «Возврат на МКАД» включён → добавляется возвратная нога;
  - адреса внутри МКАД — «зона 0 км»: ноги до съездов не добавляются;
  - тумблер «Возврат на МКАД» блокируется, если последний адрес внутри МКАД.
- Плашка с итоговым пробегом и временем; список участков маршрута; карта с маршрутом и точками съездов.
- PWA: установка на телефон как мини-приложение (Android и iOS).
- Предупреждение пользователю, если сервисы карты недоступны (например, при включённом VPN).

Структура проекта
Подробное назначение каждого файла — в PROMPT.md, раздел 5. Кратко:
- index.html — разметка страницы;
- css/styles.css — дизайн-система;
- js/app.js — интерфейс и расчёт;
- js/mkad.js — схема МКАД, съезды, точки въезда/выезда;
- js/geocoder.js — подсказки адресов и координат;
- js/router.js — маршруты OSRM;
- js/vehicles.js — типы техники и (в будущем) характеристики;
- js/config.js — токен Dadata и ручные координаты съездов;
- data/mkad-yandex.txt — точная геометрия сторон МКАД (выгрузка Яндекс.Карт);
- sw.js, manifest.webmanifest, icons/ — PWA;
- icon-export.html, junction-collector.html — служебные инструменты.

Конфигурация (js/config.js)
- DADATA_TOKEN — токен Dadata Suggestions (бесплатно 10 000 запросов/сутки).
    Пустая строка = подсказки работают через Nominatim (медленнее, без ключа).
- MKAD_JUNCTIONS_OVERRIDE — массив ручных координат съездов
    { lon, lat, side: 'outer' | 'inner' }; имеет приоритет над авто-парсингом.
    Собирать удобно страницей junction-collector.html.

Внешние сервисы
Сервис | Назначение | Ограничения
Dadata | подсказки адресов | 10 000 запросов/сутки бесплатно
Nominatim (OSM) | подсказки/reverse | не чаще 1 запроса/с (соблюдено)
OSRM demo | маршруты по дорогам | демо-сервер, для прода — своя инстанция или ORS
Overpass | съезды МКАД (фон) | может не отвечать — есть фолбэки
OSM tiles + Leaflet | карта | обязательна атрибуция © OpenStreetMap

Тестирование
Эталонные сценарии и числа — в PROMPT.md, разделы 15 и 20.
Кратко: пара «внутри + снаружи» даёт ≈43–44 км; одиночный внутренний адрес = 0,0 км;
возвратная нога ≈1,3–1,7 км без петель.
Известные ограничения
OSRM demo не предназначен для высокой нагрузки (план миграции — в PROMPT.md, раздел 17).
Токен Dadata виден в клиентском коде (допустимо для MVP; для прода — проксировать через бэкенд).
При включённом VPN на устройстве сервисы карты могут быть недоступны — показывается предупреждение.
Дорожная карта
Характеристики техники → расчёт стоимости → личный кабинет (бэкенд) → маршруты спецтехники с ограничениями.
