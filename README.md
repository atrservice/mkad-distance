# МКАД Дистанс

Калькулятор расстояний по дорогам от МКАД до адресов (ближайшие съезды).
Статическое PWA-приложение: без сервера и без затрат.

## Запуск локально
Сайт нужно открывать через HTTP-сервер (не двойным кликом по файлу):
- `npx serve .`  (нужен Node.js), либо
- расширение Live Server в VS Code.

## Публикация
GitHub Pages: Settings → Pages → Deploy from a branch → main / root.

## Бесплатные сервисы и их лимиты
- Геокодинг: Nominatim (1 запрос/сек, укажите свой e-mail при росте нагрузки).
- Маршруты: демо-сервер OSRM — только для небольших нагрузок.
- Схема МКАД: Overpass API, кэшируется в браузере на 60 дней.

## План развития
- Замена OSRM-демо на OpenRouteService (бесплатный ключ) — файл `js/router.js`.
- Личный кабинет и спецтехника — потребуется бэкенд.
