Клик по карте добавляет точку с текущими стороной/типом. Кликайте по ходу движения стороны: внешняя — против часовой, внутренняя — по часовой. Отмечайте только место примыкания рампы к полотну МКАД: съезд = рампа уходит вправо, въезд = рампа вливается справа. Маркеры: красные = внешняя, зелёные = внутренняя; светлая середина = exit, тёмная = enter.
