## Итерация 36 — способ расчёта «Стандарт/Рейсы» (КМУ), последние адреса сессии, ускорение зонда
- Блок «Способ расчета» (сегменты Стандарт/Рейсы) под «Шасси», показывается только для типов из
  REJSY_SUPPORTED (vehicles.js, сейчас ['manipulyator']) — масштабирование без правок UI.
- Режим «Рейсы»: подпись поля «За смену 7+1» → «За рейс, ₽» (значение = базовая shift, 2.9);
  поле «За час» скрыто (display:none, значение сохраняется); вместо него оранжевое поле
  «Кол-во рейсов» (type=number, min=1, default 1); список «Смена» скрыт (доп. часов нет).
  Формула: S = За рейс × кол-во + оплачиваемый пробег × км. Подпись: «Расчет = Рейс × N + …».
- Тумблер «Включено в смену» в «Рейсах» с обратным смыслом (2.7): ВКЛ → пробег в рейсе (0 в расчёте);
  ВЫКЛ → пробег отдельно, только вне МКАД. Поле км у тумблера в «Рейсах» информационное:
  автозаполняется оплачиваемым пробегом и disabled; тултип тумблера меняется по режиму.
- Переключение Стандарт↔Рейсы значения полей СОХРАНЯЕТ (2.10); сброс — только смена
  характеристики/шасси/типа или крыжик НДС.
- Контраст активных сегментов (.seg): синий фон + белый текст (все переключатели).
- Последние адреса: память сессии (TTL 30 минут, максимум 7, дедуп 50 м): фокус в пустое поле —
  список недавних; при вводе — недавние сверху (подпись «недавний») + удалённый поиск ниже
  с дедупликацией; выбор недавнего = обычное подтверждение адреса.
- Route-зонд: задержка между кандидатами 200ms → 100ms (ускорение расчёта, 429 по-прежнему
  страхуется повтором router.js через 2с).
- Глобальное [hidden]{display:none !important} — чинит скрытие flex/grid-блоков атрибутом hidden.
- sw: mkad-static-v44.
- Задеплоено: нет (внести после проверки).

## Итерация 28 — допуск bearings ±45° вместо ±180°, убран bearings из table
- Причина «Кубинка клеверница»: bearings передавались с допуском ±180° (любое направление),
  OSRM привязывал точку прямого слива к встречному полотну (внутренняя сторона), маршрут шёл
  с петлёй. Теперь bearings передаются как {bearing, tolerance: 45} — допуск ±45°, привязка
  только к правильному полотну, маршруты без петель.
- Bearings убраны из table запроса: trailing ';' в URL ломал запрос (400 Bad Request),
  а для сравнения дистанций направление не критично. Table теперь работает без bearings.
- Формат bearings: объекты {bearing, tolerance} вместо чисел; buildRoute использует tolerance
  для формирования URL (fallback на числовые bearings с допуском ±45°).
- Новопетровское: работает корректно (route-зонд выбирает правильные точки Новорижской развязки).
- sw: mkad-static-v37.
- Задеплоено: нет (внести после проверки).

## Итерация 14 — режимы «Смена», типозависимая калькуляция, оплачиваемый пробег
- «Тип техники» — выпадающий список (клик всегда показывает весь список, пункт «Выберите…»);
  комбобокс с фильтрацией убран. Список с поиском — в backlog (при росте числа типов).
- Блок «Характеристика + Смена + тултипы» полностью скрыт, пока не выбран тип техники;
  выбор «Выберите…» прячет шасси, характеристику, «Смену» и плашку цен.
- Список «Смена» рядом с «Характеристикой» (две колонки, подпись над каждым списком, тултип).
  13 режимов: без подачи 8, 9, 10, 11, 12 (техника остаётся на объекте); с подачей 7+1, 7+2, 7+3,
  8+1, 9+1, 10+1, 11+1, 12+1 (техника приезжает на объект).
- Математика смены (ФИНАЛ, подтверждено примерами пользователя): поля «За смену»/«За час» ВСЕГДА
  несут базовые значения режима 7+1 (смена из таблицы; час = смена ÷ 8, округление до рубля;
  ручные правки разрешены). Выбор режима НЕ меняет поля — к сумме добавляются доп. часы по ставке
  «За час»: доп. часы = оплачиваемые часы режима (работа + подача) − 8, не меньше 0.
  Эталон (база 16 000, час 2 000): «8» = 16 000 (+0); «12» = 24 000 (+4); «12+1» = 26 000 (+5);
  «7+3» = 20 000 (+2); «8+1» = 18 000 (+1).
  Подпись над полем — «За смену 7+1» с тултипом (разъяснение + примеры).
- Формула суммы: Сумма = смена(7+1) + (доп. часы режима + доп. часы типа) × час
  + Оплачиваемый пробег × цена/км.
- Оплачиваемый пробег (округление до целого км; на плашке — крупно, рядом «Общий пробег» мельче):
  Автовышка/Автомобиль прикрытия = весь пробег; Автокран = подача вне МКАД (если адрес 1 снаружи)
  + вне-МКАД части перебазировок адрес→адрес (возврат на базу НЕ тарифицируется);
  Кран-манипулятор = весь пробег вне МКАД (хвосты туда-обратно, движение по МКАД исключено).
- Классификация «вне МКАД» по геометрии маршрута: середина сегмента; допуск 25 м у кольца —
  движение по самой МКАД не оплачивается. Считается один раз при расчёте маршрута.
- Доп. часы типа: Автокран = адресов−1 (перебазировки); Кран-манипулятор = адресов−2 (перевозка
  входит в смену); Автовышка/Автомобиль прикрытия = адресов−1 (ДОПУЩЕНИЕ, ждёт подтверждения).
